# Data and code terms

The source road imagery and original instance annotations come from BDD100K. Refer to the [BDD100K project](https://github.com/bdd100k/bdd100k) for source-data access and terms. This repository does not assign a new license to those source files.

The author-supplied construction bundle did not include a code license. Public availability and reproducibility documentation should not be read as a new MIT, Apache or Creative Commons license for that bundle or the derived data. No such license badge is used in this release.

Manuscript-derived visual examples retain their attribution. Dataset construction sources, annotations, source images and manuscript illustrations have distinct provenance; see [Provenance](docs/PROVENANCE.md).
